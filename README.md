# Вне канала

Сатирический одностраничный манифест о том, почему закрытые чаты и «каналы для своих» затягивают: эхо-камера, сплетни, тревога и потеря границ.

## Как открыть

Просто откройте `index.html` в браузере. Сайт статический: без сборки и зависимостей. Шрифты подгружаются с Google Fonts; без интернета сработают системные.

## Локальный хост

Самый простой способ — запустить `start-server.cmd` двойным кликом. Сайт откроется на:

```text
http://127.0.0.1:8000/
```

Остановить сервер: `stop-server.cmd` или `Ctrl+C` в окне, где он запущен.

Вручную:

```powershell
cd C:\Users\edikm\vne-kanala
node server.mjs
```

Другой порт:

```powershell
$env:PORT=8001; node server.mjs
```

Или через Python:

```powershell
python -m http.server 8000
```

## Что внутри

- Тёмный лендинг с hero-блоком, сатирическим мок-чатом и бегущей строкой.
- Три вымышленных персонажа: Костя, Егор и Артём. С дисклеймером.
- Шесть причин, почему «только для своих» — не безопасная среда.
- Таймлайн «как затягивает»: один вечер изнутри.
- Интерактивный тест из шести вопросов с результатом.
- Чек-лист «неделя вне шёпота»: прогресс сохраняется в localStorage, текст можно скопировать.
- Мобильная навигация, анимации появления при скролле, кнопка «Поделиться».
- Адаптивная вёрстка и поддержка `prefers-reduced-motion`.

## Файлы

- `index.html` — разметка и весь контент.
- `styles.css` — оформление, адаптив, анимации.
- `app.js` — тест, чек-лист, мобильное меню, копирование, share.
- `server.mjs` — локальный статический сервер на Node.js.
- `start-server.cmd` / `stop-server.cmd` — запуск и остановка на Windows.
- `README.md` — этот файл.

## Важно

Персонажи и истории вымышлены. Сайт не предназначен для травли реальных людей. Если публикуете его, сохраните дисклеймер и не подставляйте имена реальных знакомых в негативный контекст.

## Кастомизация

- Цвета — переменные в `:root` в начале `styles.css` (`--lime`, `--pink`, `--bg`).
- Тексты, карточки и персонажи — в `index.html`.
- Вопросы теста — массив `quizQuestions` в `app.js`.
- Пункты чек-листа — в `index.html`; ключ сохранения — `CHECKLIST_KEY` в `app.js`.
